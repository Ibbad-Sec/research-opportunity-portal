# 🎓 Research Opportunity Portal

A centralized web-based portal for managing university research opportunities.

## 📌 Overview

Faculty members can post, view, update, and manage research opportunities in one place. Students can browse all available opportunities with complete details.

## 🛠️ Tech Stack

| Layer    | Technology                |
|----------|---------------------------|
| Backend  | Python + FastAPI          |
| Database | MySQL 26.7                |
| Frontend | React.js + Bootstrap      |
